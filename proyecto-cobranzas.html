Desarrollo

¿Qué hice?

Participé en el desarrollo de la solución desde la preparación de información hasta la construcción y publicación del dashboard.

Datos y SQL Server

  • Integración de información proveniente de diferentes tablas y fuentes.
  • Construcción y optimización de consultas mediante múltiples JOIN.
  • Uso de CTE y tablas temporales para organizar y procesar información.
  • Tratamiento de valores nulos, tipos de datos y campos inconsistentes.
  • Extracción y transformación de información mediante funciones SQL.
  • Centralización de información que anteriormente se encontraba distribuida en Excel y diferentes consultas.

Power BI y análisis

  • Preparación y transformación de datos mediante Power Query y lenguaje M.
  • Creación de medidas DAX e indicadores según requerimientos del negocio.
  • Construcción de filtros y visualizaciones orientadas al análisis de cobranzas.
  • Organización de información para diferentes jefaturas y gerencias.
  • Desarrollo de una herramienta interactiva para consulta y seguimiento.
  • Implementación de actualización automática mediante Power BI Gateway.

Solución

Centralización y mejora del análisis

Necesidad y solución

La información de cobranzas se encontraba distribuida entre diferentes fuentes, consultas y archivos Excel, lo que generaba dependencia de revisiones manuales para obtener una visión consolidada.

La solución permitió centralizar esta información y convertirla en una herramienta interactiva y actualizable, facilitando la consulta de montos pendientes, vencimientos, clientes y diferentes situaciones de cobranza.

Resultado

  • ✓ Información centralizada
  • ✓ Menor dependencia de revisiones manuales
  • ✓ Consultas y análisis más ágiles
  • ✓ Actualización automática desde la base de datos
  • ✓ Información disponible para las áreas involucradas
