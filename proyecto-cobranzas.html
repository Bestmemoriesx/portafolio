Dashboard de Cobranzas

Solución desarrollada para centralizar la información de cobranzas, facilitar su análisis y optimizar el acceso a información actualizada para las áreas involucradas.

Contexto

Necesidad identificada

La información relacionada con las cobranzas se encontraba distribuida en diferentes fuentes y consultas, por lo que se requería una revisión manual en Excel para obtener una visión general de la situación.

Esta distribución dificultaba disponer rápidamente de una visión consolidada de montos pendientes, vencimientos, clientes y diferentes situaciones de cobranza. Por este motivo, se centralizó la información de facturación, se realizó la limpieza de los datos y se crearon columnas adicionales para englobar los diferentes reportes en una sola solución.

Desarrollo

Lo que se desarrolló

01 · DATOS

Fuentes

Se trabajó con información proveniente de Excel y SQL Server. La información de Excel fue llevada a la base de datos para mantenerla centralizada y evitar pérdida o dispersión de información.

02 · SQL

Preparación

Se utilizaron tablas temporales para agilizar las actualizaciones. Se realizó limpieza de filas nulas, diferencias de tipos de datos y extracción de cadenas de texto. Finalmente, se generó una vista optimizada mediante JOIN entre una cantidad considerable de tablas.

03 · ORGANIZACIÓN

Información consolidada

Se integraron diferentes vistas utilizadas por jefaturas y gerencia en un sistema común, de manera que la información pueda utilizarse tanto en reuniones como para las consultas de los usuarios.

04 · BI

Visualización

Se desarrollaron medidas e indicadores considerando las necesidades de los usuarios, además de filtros y permisos por gerencia para compartir la información correspondiente sin exponer información de otras áreas.

Solución e impacto

Centralizar el análisis

Se construyó una herramienta de análisis que permite visualizar la situación de las cobranzas de manera clara, interactiva y actualizable. El dashboard reúne KPIs gerenciales y el detalle necesario para la consulta de cada jefatura o gerencia.

La solución permite manejar la información de manera precisa y mantenerla actualizada automáticamente desde la base de datos hacia la nube mediante Power BI Gateway. Esto reduce el tiempo de consulta de los usuarios y facilita el acceso a la información a través de Teams.

Información centralizada Reportes de facturación consolidados en una única herramienta.
Información actualizada Actualización automática desde la base de datos mediante Gateway.
Acceso optimizado Información disponible para los usuarios y áreas correspondientes desde Teams.
