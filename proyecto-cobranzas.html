Dashboard de Cobranzas

Desarrollo de un dashboard orientado al seguimiento de cobranzas, centralizando información para facilitar el análisis de cuentas por cobrar y la identificación de situaciones que requieren seguimiento.

El problema

La información relacionada con las cobranzas se encontraba distribuida en diferentes fuentes y requería revisión manual para obtener una visión general de la situación.

Esto dificultaba tener rápidamente una visión consolidada del monto pendiente, vencimientos, clientes y comportamiento de la cartera.

Objetivo

Centralizar la información y construir una herramienta de análisis que permita visualizar la situación de las cobranzas de manera clara, interactiva y actualizable.

Proceso de desarrollo

01 · Datos Identificación y recopilación de las fuentes necesarias.
02 · SQL Preparación y consulta de información mediante SQL Server.
03 · Modelo Transformación y organización de los datos para el análisis.
04 · BI Creación de medidas, indicadores y visualizaciones en Power BI.

Tecnologías utilizadas

SQL Server Power Query DAX Power BI Power BI Service Gateway

Dashboard

Vista interactiva desarrollada para facilitar el seguimiento y análisis de la cartera de cobranzas.

Aquí colocaremos posteriormente una captura y/o el dashboard interactivo de Power BI.

Resultado

El dashboard permite disponer de una vista centralizada de la información y facilita la identificación de montos pendientes, vencimientos y segmentos que requieren mayor seguimiento.
