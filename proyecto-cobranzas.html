Dashboard de Cobranzas

Desarrollo de una herramienta de análisis para centralizar, consultar y realizar seguimiento de la información relacionada con las cobranzas.

PROYECTO

Vista del desarrollo

1 / 6
DESARROLLO

Construcción de la solución

01 · DATOS

Fuentes de información

Integración de información proveniente de Excel y SQL. La información utilizada en archivos Excel fue llevada a la base de datos para evitar dispersión y pérdida de información.

02 · SQL

Preparación y optimización

Creación de tablas temporales, tratamiento de valores nulos, diferencias de tipos de datos y extracción de información desde cadenas de texto. Se generó una vista optimizada mediante la integración de múltiples tablas.

03 · ORGANIZACIÓN

Unificación de información

Se integraron diferentes vistas utilizadas por jefaturas y gerencia en un único sistema, permitiendo utilizar la misma herramienta tanto para reuniones como para consultas de los usuarios.

04 · BI

Análisis y visualización

Creación de medidas y visualizaciones considerando las necesidades de cada usuario, junto con filtros y control de acceso por gerencia y jefatura.

RESULTADO

Solución e impacto

Se construyó una herramienta de análisis sostenible para el control de las cobranzas, integrando la información en un único sistema de consulta.

La conexión entre Power BI y la base de datos mediante Gateway permite mantener la información actualizada, facilitando el acceso a datos recientes y reduciendo la dependencia de procesos manuales.

La información está disponible tanto para el uso gerencial como para la consulta de los diferentes usuarios de la empresa, incorporando RLS (Row-Level Security) por gerencia y jefatura para controlar el acceso según cada área.

Como resultado, se disminuyó el tiempo destinado a la consulta y recopilación de información, contando con un sistema centralizado y optimizado para el seguimiento y control de las cobranzas.

Información centralizada

La información necesaria para el seguimiento de cobranzas se concentra en una única herramienta.

Actualización continua

Conexión mediante Power BI Gateway para mantener la información actualizada desde la base de datos.

Acceso controlado

RLS por gerencia y jefatura para gestionar el acceso a la información según cada área.
