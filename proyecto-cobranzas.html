Contexto

De información dispersa a una herramienta de análisis

El proyecto surgió a partir de la necesidad de disponer de una visión consolidada de la situación de cobranzas y reducir la dependencia de revisiones manuales.

Problema

La información relacionada con las cobranzas se encontraba distribuida entre diferentes fuentes, consultas y archivos Excel. Esto requería revisiones manuales para obtener una visión general de montos pendientes, vencimientos, clientes y situaciones.

Solución

Se centralizó la información en una solución de análisis, integrando datos provenientes de SQL Server y Excel, realizando procesos de limpieza, transformación y organización para consolidarlos en un único dashboard.

Resultado

Se obtuvo una herramienta interactiva y actualizable que facilita la consulta de información, permite analizar el estado de las cobranzas y reduce el tiempo necesario para obtener información consolidada.

Desarrollo

Proceso de construcción

El desarrollo involucró integración de fuentes, preparación de datos, optimización de consultas y construcción de una solución orientada a las necesidades de análisis de las áreas involucradas.

01 · DATOS

Integración de fuentes

Se integró información proveniente de SQL Server y archivos Excel. La información utilizada en Excel fue incorporada al flujo de datos para mantenerla centralizada y evitar su dispersión.

02 · SQL

Preparación y optimización

Se realizaron procesos de limpieza y transformación, incluyendo tratamiento de valores nulos, conversión de tipos de datos, extracción de información y consultas con múltiples JOIN. También se utilizaron tablas temporales para optimizar procesos de actualización.

03 · MODELO

Organización de la información

Se consolidaron diferentes vistas utilizadas por jefaturas y gerencia, organizando la información para facilitar tanto el análisis durante reuniones como la consulta individual de datos.

04 · BI

Análisis y visualización

Se desarrollaron medidas, indicadores y filtros de acuerdo con las necesidades del negocio, incorporando mecanismos de acceso según las áreas y gerencias correspondientes.

Impacto

Resultado de la solución

La solución permitió disponer de una herramienta centralizada para gestionar y consultar la información de cobranzas de manera más rápida y estructurada. El dashboard se conecta a la base de datos mediante Power BI Gateway, permitiendo mantener la información actualizada automáticamente y disponible desde la plataforma utilizada por los usuarios.

Centralización
Información consolidada en una única herramienta de análisis.
Optimización
Menor dependencia de consultas y revisiones manuales.
Actualización
Información conectada a la base de datos mediante Gateway.
