Dashboard de Cobranzas

Solución desarrollada para centralizar la información de facturación y cobranzas y convertirla en una herramienta de consulta y seguimiento para las diferentes áreas.

01 · Necesidad

¿Por qué se construyó?

La información relacionada con las cobranzas se encontraba distribuida entre diferentes fuentes, consultas y archivos Excel. Para obtener una visión general era necesario realizar revisiones manuales, lo que dificultaba consultar rápidamente montos pendientes, vencimientos, clientes y situaciones de cobranza.

Objetivo: centralizar la información y construir una herramienta de análisis que permitiera visualizar la situación de las cobranzas de forma clara, interactiva y actualizable, reduciendo la dependencia de revisiones manuales.

02 · Desarrollo

De múltiples fuentes a una sola herramienta

01 · DATOS

Integración

Se reunieron fuentes provenientes de SQL Server y Excel. La información de Excel fue incorporada a la base de datos para centralizarla y evitar pérdida de información.

02 · SQL

Preparación

Se limpiaron datos nulos y tipos inconsistentes, se extrajeron valores de cadenas y se construyó una vista optimizada mediante múltiples JOIN. También se utilizaron tablas temporales para agilizar las actualizaciones.

03 · MODELO

Organización

Se integraron diferentes perspectivas de jefaturas y gerencias dentro de una misma estructura, permitiendo utilizar la información tanto para reuniones como para consultas operativas.

04 · BI

Análisis y acceso

Se desarrollaron medidas, KPIs y filtros según las necesidades de los usuarios. El acceso por gerencia permite compartir la información correspondiente a cada área.

03 · Dashboard

Una misma información, diferentes niveles de análisis

El dashboard fue estructurado para presentar indicadores gerenciales y, al mismo tiempo, permitir profundizar en el detalle necesario para cada jefatura o gerencia.

04 · Resultado

Información más accesible y oportuna

De revisiones manuales a una herramienta centralizada

La solución permitió reunir la información de facturación en una herramienta sistemática, reduciendo el tiempo de consulta y facilitando el acceso a información actualizada. La conexión mediante Power BI Gateway permite actualizar automáticamente la información desde la base de datos hacia la nube, mientras que su disponibilidad en Teams facilita el acceso a los usuarios autorizados.
