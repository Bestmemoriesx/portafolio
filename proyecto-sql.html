03 · Ejemplo técnico

Consulta SQL

Ejemplo demostrativo de una consulta que combina información de diferentes tablas y aplica transformación de datos.

consulta-ventas.sql 
SELECT
    v.IdVenta,
    v.Fecha,
    c.Cliente,
    v.Total,
    ISNULL(v.Estado, 'SIN ESTADO') AS Estado

FROM Ventas v

LEFT JOIN Clientes c
    ON c.IdCliente = v.IdCliente

WHERE v.Fecha >= '2026-01-01'

ORDER BY v.Fecha DESC;
Este código es un ejemplo demostrativo creado para el portafolio. No corresponde a consultas ni estructuras internas de la empresa.
