01 · Experiencia

Trabajo con información empresarial

Durante mi experiencia profesional he trabajado principalmente con SQL Server y T-SQL, utilizando consultas y estructuras SQL para obtener, transformar, validar y organizar información utilizada por diferentes procesos y usuarios.

02 · Evidencia técnica

Código SQL

Algunos ejemplos representativos de las estructuras y técnicas que utilizo para trabajar con información.

consulta-integracion.sql
``` 
SELECT
    v.IdVenta,
    v.Fecha,
    c.Cliente,
    v.Total,
    ISNULL(v.Estado, 'SIN ESTADO') AS Estado

FROM Ventas v

LEFT JOIN Clientes c
    ON c.IdCliente = v.IdCliente

WHERE v.Fecha >= '2026-01-01'

ORDER BY v.Fecha DESC;
```
Ejemplo demostrativo de integración entre tablas y tratamiento de valores nulos mediante JOIN e ISNULL.
procedimiento-repetitivo.sql
``` 
DECLARE @FechaInicio DATE = '2026-01-01';
DECLARE @FechaFin DATE = '2026-01-31';

SELECT
    Fecha,
    Cliente,
    Total
FROM Ventas
WHERE Fecha BETWEEN @FechaInicio AND @FechaFin
ORDER BY Fecha DESC;
```
Ejemplo de uso de variables y DECLARE para preparar consultas reutilizables en actividades de consulta repetitiva.
analisis-registros.sql
``` 
WITH Datos AS (

    SELECT
        Cliente,
        Fecha,
        Total,

        ROW_NUMBER() OVER(
            PARTITION BY Cliente
            ORDER BY Fecha DESC
        ) AS Orden

    FROM Ventas

)

SELECT *
FROM Datos
WHERE Orden = 1;
```
Ejemplo de utilización de CTE y ROW_NUMBER para organizar y analizar registros dentro de una consulta.
Los ejemplos mostrados son demostrativos y han sido creados específicamente para el portafolio. No corresponden a consultas, estructuras ni información interna de la empresa.
